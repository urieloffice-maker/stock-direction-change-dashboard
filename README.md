# דשבורד סיכון לשינוי מגמה — S&P 500

דשבורד שמתעדכן אוטומטית, בלי שרת, בחינם, דרך GitHub Actions + GitHub Pages.

## איך זה עובד

```
┌─────────────────────┐     כל 4 שעות      ┌──────────────────┐
│  GitHub Actions      │ ─────────────────▶ │  scripts/         │
│  (cron scheduler)    │                    │  fetch_data.py     │
└─────────────────────┘                    └──────────┬────────┘
                                                        │ מושך נתונים חיים
                                                        │ (Yahoo Finance)
                                                        ▼
                                              מחשב את כל 6 האינדיקטורים
                                              + ציון סיכון משוקלל
                                                        │
                                                        ▼
                                              כותב את data.json
                                              ומבצע commit + push
                                                        │
                                                        ▼
                                              GitHub Pages מגיש את
                                              index.html שקורא את
                                              data.json בכל טעינה
```

אתם פותחים כתובת אחת קבועה בכל עת — הנתונים תמיד עדכניים לפי הריצה האחרונה.

## הקמה (5 דקות)

1. **צרו ריפוזיטורי חדש ב-GitHub** (מומלץ Public — כך Actions בחינם וללא הגבלת דקות).
2. **העלו את כל הקבצים** מהתיקייה הזו לריפו, בשמירה על מבנה התיקיות:
   ```
   index.html
   data.json
   requirements.txt
   scripts/fetch_data.py
   .github/workflows/update-data.yml
   README.md
   ```
3. **אפשרו הרשאות כתיבה ל-Actions** (חובה, אחרת ה-commit האוטומטי ייכשל):
   Settings → Actions → General → Workflow permissions → בחרו **"Read and write permissions"** → Save.
4. **הפעילו GitHub Pages**:
   Settings → Pages → Source: **Deploy from a branch** → Branch: **main**, תיקייה **/ (root)** → Save.
   GitHub ייתן לכם כתובת בסגנון `https://<username>.github.io/<repo-name>/`.
5. **הריצו את ה-Action ידנית בפעם הראשונה** (אין צורך לחכות ל-cron):
   לשונית **Actions** → בחרו **"Update market risk data"** → **Run workflow** → **Run workflow**.
   הריצה לוקחת כ-2–4 דקות (בעיקר בגלל חישוב S5FI על פני כל 500 מניות המדד).
6. אחרי שהריצה מסתיימת בהצלחה (סימן ✓ ירוק), פתחו את כתובת ה-Pages — תראו את הנתונים החיים.

## תדירות עדכון

כברירת מחדל ה-workflow רץ **כל 4 שעות** (`0 */4 * * *`, בשעון UTC).
לשינוי התדירות, ערכו את השורה ב-`.github/workflows/update-data.yml`:

| רוצים | cron |
|---|---|
| כל 4 שעות (ברירת מחדל) | `0 */4 * * *` |
| כל 6 שעות | `0 */6 * * *` |
| פעם ביום, 22:00 UTC (אחרי סגירת ארה"ב) | `0 22 * * *` |

⚠️ GitHub לא מבטיח דיוק מלא בזמני ה-cron בעומס גבוה — לרוב עיכוב של עד כמה דקות, זה תקין.

## מה אם משהו נכשל?

- **הריצה נכשלת על S5FI** (בעיית רשת מול Wikipedia/Yahoo) — הסקריפט עדיין יכתוב את שאר 5 האינדיקטורים ויסמן את S5FI כ"לא זמין" באותה ריצה; הריצה הבאה תנסה שוב.
- **data.json לא מתעדכן** — בדקו בלשונית Actions שה-workflow רץ בהצלחה, ושהרשאות ה-write מופעלות (שלב 3 למעלה).
- **הדף מציג "לא ניתן לטעון נתונים"** — לרוב סימן שה-Action עוד לא רץ אף פעם. הריצו ידנית (שלב 5).

## הרחבות אפשריות

- הוספת התראה (Slack/Telegram/מייל) כשהציון חוצה סף מסוים — אפשר להוסיף כשלב נוסף ב-workflow.
- שמירת היסטוריית ציונים יומית לקובץ נפרד (`history.json`) לצורך גרף מגמת הסיכון לאורך זמן.
- מעבר למקור נתונים בתשלום (כגון Alpha Vantage / Financial Modeling Prep) אם רוצים יציבות גבוהה יותר מ-Yahoo Finance.

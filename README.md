📊 דשבורד ניתוח סיכון לשינוי מגמה בשוק ההון

דשבורד אינטראקטיבי ואוטומטי המיועד לזהות מצבי מתיחת-יתר, היחלשות פנימית בשוק (Internal Weakness) ועלייה בסבירות לתיקון בטווח הקצר (Short-term Correction Risk) עבור מדדי המניות המובילים בארה"ב: S&P 500, NASDAQ, QQQ, ו-Russell 2000.

הדשבורד מתעדכן אוטומטית בכל יום מסחר בסגירת המסחר באמצעות GitHub Actions.
🎯 מטרת המערכת והשימוש בה

המערכת אוספת ומנתחת שישה אינדיקטורים מובילים מעולם ה-Market Breadth (רוחב שוק) וה-Technical Analysis כדי לספק ציון סיכון משוקלל בטווח של 0–100.

במקום להסתכל רק על המחיר של המדד, הדשבורד בודק "מה קורה מתחת למכסה המנוע" — האם המניות הקטנות משתתפות בעלייה, האם הסקטורים ההגנתיים מתחזקים, והאם השוק נמצא בשאננות מוגזמת.
🧭 איך לקרוא את הנתונים במסך? (Guiding Principles)
1. מבט חטוף (Quick-Look Gauge)

בראש העמוד מופיע מד חוגה (Speedometer) וכרטיסיית סטטוס בולטת:

    0–30 (ירוק) — סיכון נמוך: השוק במצב בריא וחזק. אין סימנים קריטיים לתיקון.

    31–50 (צהוב) — סיכון מתון: השוק תקין, אך נדרש מעקב אחר סקטורים ספציפיים.

    51–70 (כתום) — סיכון גבוה: מתיחת-יתר או סטיות ברוחב השוק/סנטימנט. מומלץ לנהל סיכונים ולהדק סטופים.

    71–100 (אדום) — סיכון גבוה מאוד: מתיחת-יתר עמוקה או חולשה פנימית חריפה. הסבירות לתיקון בטווח הקצר גבוהה מאוד.

📐 פירוט ששת האינדיקטורים והרף הקריטי
שם האינדיקטור	מה הוא בודק?	רף קריטי / תנאים	המשמעות והסטטוס
מרחק מממוצע 150 יום	מרחק המחיר מהממוצע הארוך	

• מעל 10%: התחלת אזהרה

• מעל 15%: מתיחת-יתר
	בודק האם המחיר ברח רחוק מדי מהממוצע הנע ההיסטורי שלו.
רוחב שוק (RSP מול המדד)	השוואה בין משקל שווה למשקל שוק	

• מדד עולה + RSP יורד: אזהרה

• שניהם עולים: בריא
	בודק האם כלל המניות מניעות את השוק או רק מניות הליבה הגדולות.
סנטימנט ופחד (VIX)	תנודתיות ושאננות משקיעים	

• מתחת ל-14: אזהרת שאננות

• 14–20: ניטרלי

• מעל 20: פחד/תנודתיות
	VIX נמוך מאוד מעיד על שאננות יתר המקדימה לעיתים קרובות תיקונים.
רוטציה הגנתית (XLP/SPX)	יחס סקטור צריכה בסיסית למדד	

• מגמת עלייה: מעבר להגנה

• מגמת ירידה: העדפת סיכון
	מעקב בנתיבי 20, 50 ו-100 ימי מסחר לזיהוי בריחת כסף לסקטורים הגנתיים.
תיאבון לסיכון (XLY/XLP)	יחס צריכה מחזורית לצריכה בסיסית	

• מגמת ירידה: ירידה בתיאבון לסיכון

• מגמת עלייה: מצב חיובי
	בודק האם המשקיעים מעדיפים מניות צמיחה/מחזוריות או מניות מקלט.
S5FI (מניות מעל ממוצע 50)	אחוז מניות המדד הנסחרות מעל SMA50	

• מעל 70%: שוק חם/מתוח

• 50%–70%: חיובי

• מתחת ל-50%: חולשה
	מודד את הבריאות הפנימית של מניות השוק.

⚙️ ארכיטקטורה ואוטומציה
Plaintext

GitHub Actions (Cron Job Daily at 23:00 UTC)
     │
     ▼
fetch_data.py  ───►  yfinance (Pull Market Data)
     │
     ▼
data.json (Calculated Risk Scores & Ratios)
     │
     ▼
GitHub Pages ───►  index.html (RTL Dashboard with Chart.js & Gauge)

    fetch_data.py: מושך נתונים יומיים מ-yfinance, מחשב יחסים, ממוצעים נעים, ניקוד משוקלל וטרנדים לכל מדד.

    update-data.yml: מריץ את סקריפט הפייתון אוטומטית בימים שני–שישי ושומר את התוצאות ב-data.json.

    index.html: טוען את data.json ומציג ממשק בעברית עם פונטים מוגדלים, מד חוגה וטבלאות קריאות.

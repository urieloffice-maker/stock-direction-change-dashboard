📊 דשבורד מתקדם לזיהוי סיכוני שוק ורוטציית סקטורים

מערכת ניתוח ואוטומציה אינטראקטיבית המיועדת לזהות מצבי מתיחת-יתר, חולשה פנימית בשוק (Internal Weakness), סטיות שליליות וסכנה לתיקון בטווח הקצר עבור המדדים המובילים בארה"ב: S&P 500, NASDAQ, QQQ, ו-Russell 2000.

הדשבורד מתעדכן אוטומטית 3 פעמים במהלך יום המסחר (פתיחה, אמצע וסגירה) באמצעות GitHub Actions.
🎯 מטרת המערכת והחידושים

המערכת אוספת ומנתחת שבעה אינדיקטורים קריטיים, מציגה מיפוי מלא של 11 סקטורים, ומחשבת ציון סיכון משוקלל בטווח של 0–100.
🌟 חידושים מרכזיים במערכת:

    מיפוי סקטורים בזמן אמת: סריקת 11 סקטורי ה-S&P 500 (XLK, XLF, XLP וכו') וזיהוי סקטורים חזקים מול נחלשים.

    גרף היסטוריית סיכון (30 ימים): מעקב אחר מגמת ציון הסיכון לאורך זמן לזיהוי שינויי קצב.

    זיהוי סטיות שליליות (Bearish Divergence): אלגוריתם המזהה באופן אוטומטי מצב שבו המדד בשיא אך רוחב השוק נחלש.

    יחס אופציות (Put/Call Ratio): שילוב סנטימנט נגזרים לצד מדד ה-VIX.

    התראות בזמן אמת ל-Telegram: שליחת הודעת אזהרה לטלגרם ברגע שציון הסיכון חוצה את רף ה-70.

🧭 איך לקרוא את הנתונים במסך?
1. מד חוגה (Quick-Look Gauge) & רמות סיכון

    0–30 (ירוק) — סיכון נמוך: השוק במצב בריא וחזק. אין אינדיקציות קריטיות לתיקון.

    31–50 (צהוב) — סיכון מתון: השוק תקין, אך נדרש מעקב אחר סקטורים נחלשים.

    51–70 (כתום) — סיכון גבוה: מתיחת-יתר או סטיות ברוחב השוק/סנטימנט. מומלץ להימנע מכניסות חדשות.

    71–100 (אדום) — סיכון גבוה מאוד: חולשה פנימית עמוקה או מתיחת-יתר חריפה. הסבירות לתיקון בטווח הקצר גבוהה מאוד.

📲 הגדרת התראות Telegram (אופציונלי)

כדי לקבל התראה לטלגרם ברגע שציון הסיכון חוצה את רף ה-70:

    צור בוט דרך @BotFather והעתק את ה-TELEGRAM_BOT_TOKEN.

    קבל את ה-ID האישי שלך דרך @userinfobot (TELEGRAM_CHAT_ID).

    היכנס ב-GitHub ל-Settings -> Secrets and variables -> Actions.

    הוסף שני Secrets חדשים עם השמות והערכים הללו.
